
### Tests à Effectuer

#### 1. Page Finance (2 min)
```
1. Aller sur http://localhost:3000/finance
2. Voir les 3 onglets : Devis | Factures | Avoirs
3. Cliquer sur "Devis"
4. Cliquer "Créer un devis"
5. Dialog s'ouvre avec liste des tickets
```

#### 2. Créer un Devis (3 min)
```
1. Sélectionner un ticket
2. Valider (validité 30 jours par défaut)
3. Redirection vers page devis
4. Voir l'alert "Valide jusqu'au..."
5. Ajouter des lignes (pièces + main d'œuvre)
```

#### 3. Convertir en Facture (2 min)
```
1. Sur la page devis
2. Cliquer "Convertir en facture"
3. Confirmer
4. Redirection vers la nouvelle facture
5. Vérifier toutes les lignes copiées
```

#### 4. Depuis un Ticket (3 min)
```
1. Ouvrir un ticket
2. Voir section "Facturation"
3. Cliquer "Créer un devis"
4. Devis créé et visible dans la liste
5. Cliquer "Convertir" sur le devis
6. Facture créée !
```
